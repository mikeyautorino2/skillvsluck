# Simulated Leagues

This folder contains code and outputs for **season simulations** built from our cleaned, standardized match logs. The goal is to create “simulated" seasons where match results are generated by simple rules (e.g., an unbiased coin flip) so we can compare real-world patterns (home advantage, upsets, point distributions) to what we’d expect by chance.

---
## What’s here

- Per-league simulated match files produced by the notebook (e.g., `bundesliga_simulated_matches.csv`).
- (Optional) **`seeds/`** – If used, stores random seeds for reproducibility.

## Baseline simulation (33/33/33)

The current baseline uses a **uniform draw** over three outcomes for each match:

- With probability `1/3`: home win (`+1`)
- With probability `1/3`: draw (`0`)
- With probability `1/3`: home loss (`-1`)

## What each file includes:
- **Keeps the actual result** as `true_home_team_result` (the original `hometeamresult`).
- **Generates a simulated result** `simulated_home_team_result ∈ {1,0,-1}` via the 33/33/33 rule.

> ⚠️ Goals are **not** re-simulated in this. Use the `simulated_home_team_result` column—not goals—when computing simulated tables/standings.
